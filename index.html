🦅 扑翼机 · 网页遥控

用手机浏览器的 Web Bluetooth 直连机上蓝牙模块（JDY-23）

遥控（新版）推荐 配当前 flyer_fw 固件。油门 / 差速 / 升降 + 急停 + 回中 + 升降自检， 并实时解析飞控回传（收到油门= / 扑动= / 接管锁=）。
⚠ 油门需 ≥45 才会扑动。 地面站（旧版）旧固件 配早期蓝板固件（靠 0x81 状态帧、带回读 PPM CH1~CH3）。
换用 flyer_fw 后它收不到状态回读，仅作备份保留。
使用前提
· 手机必须是 Android + Chrome/Edge；iPhone/iPad 用不了（iOS 不提供 Web Bluetooth）
· 页面必须是 https（本站即是）或 localhost，否则浏览器不给蓝牙权限
· 飞控 DEBUG_SERIAL 置 1 才能看到状态回传
· 蓝牙模块上电默认 9600，固件 SERIAL_BAUD 需与之一致
